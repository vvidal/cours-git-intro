Avant de commencer : Installer et configurer Git

  • Installer Git sur votre ordinateur :
    • Windows, Linux, Mac : git-scm.com/downloads
    • Optionnel (Windows uniquement) : TortoiseGit (interface graphique)
  • Configurer votre identité Git (obligatoire avant tout commit) :
    1. Vérifier la configuration actuelle :
      git config --global user.name
      git config --global user.email
    2. Si besoin, configurer votre nom et adresse mél :
      git config --global user.name "NOM PRENOM"
      git config --global user.email "prenom.nom@etu.univ-lyon1.fr"
    Cette étape est indispensable pour valider vos modifications sur Git.
